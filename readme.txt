# NataFin

NataFin adalah aplikasi pengelolaan keuangan sehari-hari yang membantu
pengguna mencatat pemasukan dan pengeluaran serta memantau target tabungan.

## Halaman Aplikasi

- Dashboard: Menampilkan ringkasan keuangan dan daftar transaksi.
- Tambah Transaksi: Menyediakan formulir pencatatan transaksi.
- Detail Keuangan: Menampilkan ringkasan keuangan, target tabungan, dan rincian pengeluaran.

## Teknologi

- HTML5
- CSS3
- Bootstrap 5

## Alasan Memilih Bootstrap

Bootstrap dipilih karena menyediakan komponen antarmuka siap pakai dan
sistem grid yang responsif. Komponen seperti navbar, card, tabel, form,
dan tombol membantu pengembangan tampilan NataFin secara konsisten
pada perangkat desktop maupun mobile.
